# svganimate.ai 实测记录

**测试时间**：2026-11-10 14:05–14:50（UTC+8）
**测试入口**：<https://svganimate.ai/zh/home> → `/zh/create`
**测试目标**：用它做一支「衡阳建行 vs 农行网点分布」的卫星地图讲解视频

## 一、这个产品能做什么

| 项目 | 实测结果 |
|---|---|
| 产品定位 | 输入一句话 / 脚本，AI 自动生成逐字稿、分镜、旁白、字幕和对应的 HTML/SVG 场景 |
| 视频类型 | 首页列出 30 种风格，其中包含 **「卫星地图讲解」**、地图历史叙事、数据可视化等 |
| 模式 | 「HTML 视频」与「SVG 动画」两种 |
| 模型 | 界面显示可选 Gemini 3.8 Flash，顶部横幅提示已支持 Claude Opus 5.5 / Sonnet 5.5 |
| 导出 | 页面 FAQ 称支持 GIF、MP4、HTML；MP4 异常时可用「直接录屏」 |
| 商用 | 页面称生成动效归用户所有，可商用 |
| API / MCP / CLI | **未提供**，官网只有网页端创作入口 |

## 二、实际跑一遍的结果

1. 打开 `/zh/create`，选择「卫星地图讲解」风格；
2. 在描述框里填入本项目的需求（建行 43 个 / 农行 98 个网点、市区 vs 县域、卫星推近 + 双色点亮 + 分屏对比）；
3. 点击「一键生成视频」；
4. **弹出「请登录后继续」**，只提供 **微信** 和 **Google** 两种登录方式，没有游客试用、没有邮箱注册。

未登录状态下：不能生成、不能预览、不能导出。截图见 [`svganimate-login.png`](./svganimate-login.png)。

## 三、为什么最终没有用它出片

除了登录门槛，还有三个与本任务冲突的硬限制：

1. **无法导入结构化数据**：输入区只支持文字和「添加图片附件」，不能上传 141 个网点的经纬度表，生成的只能是"看起来像"的地图，不是真实坐标。
2. **产品自述不适合写实图像**：FAQ 明确写「SVG 动画基于代码生成，适合点线面体等几何元素，可以抽象表达事物，但**不适合生成现实风格的图像**」。而本项目需要真实卫星影像。
3. **无法程序化调用**：没有 API/CLI，无法接入「渲染 → 校验 → 重跑」的流水线，也无法保证每次生成的地理位置一致。

## 四、结论

- **它擅长的**：风格化、节奏快、带旁白字幕的知识讲解片，尤其是不要求地理精度的「地图叙事」。
- **它不擅长的**：需要真实坐标、真实卫星底图、可核验统计口径的数据视频。
- **本项目的选择**：保留 svganimate「卫星地图讲解」的叙事结构（推近 → 点亮 → 对比 → 结论），但用 **MapLibre + 高德卫星瓦片 + 逐帧渲染** 自建管线，保证每一个光点都对应一个真实网点。

## 五、如果之后想继续试

登录后可以直接复用下面的提示词（也可在网页里手动改）：

```text
用卫星地图讲解风格制作中文视频：湖南省衡阳市中国建设银行与中国农业银行营业网点分布对比。
建行43个营业网点，农行98个；建行53%集中在市区四区，农行71%分布在县域。
要求卫星影像从中国推近到衡阳，先点亮建行蓝色网点，再点亮农行绿色网点，最后分屏对比。
旁白把建行比作守城、农行比作下乡。
```

> 注意：即便登录，生成结果里的网点位置也不会等于真实坐标，只能当作风格化示意。
